# 备份、恢复与配置分享

Moonlight V+ 的“备份与同步”用于保存这台设备上的设置与配对状态；分享单个 Crown 配置是另一条流程。**完整备份包含主机配对身份等敏感数据，请勿作为公开分享包上传。**

| 你的目的 | 应该怎么做 |
| --- | --- |
| 在这台设备上恢复设置 | 保存完整备份，并记住备份密码 |
| 换一台设备 | 在新设备重新配对电脑，单独导出需要的 Crown 配置 |
| 把按键布局分享给别人 | 只使用 Crown 配置的导出或分享入口 |

## 备份会包含什么

完整备份可能包含设置、游戏预设、Crown 配置，以及已配对电脑和设备身份等信息。恢复前，应用会列出可恢复的内容；请以这个预览为准。完整备份主要用于原设备恢复，不适合直接发给别人或用来给新设备恢复配对。

## 保存一份可恢复的备份

1. 进入设置中的“备份与同步”，使用“保存备份文件”导出加密备份，并记录文件位置。如果还没有设置备份密码，应用会先要求设置；如果已有密码，这次导出会沿用它。
2. 若要持续保存到指定文件夹，先选择“备份文件夹”，设置备份密码，再使用“把备份保存到所选文件夹”。也可以选择云盘应用提供的文件夹；文件是否上传由云盘应用负责。
3. 妥善保管备份密码。重装应用或清除数据后，原设备上记住的密码可能不在；没有密码便无法预览和恢复受密码保护的备份。
4. 定期确认“自动同步状态”或手动保存后的提示，避免把尚未成功写入的文件当成备份。

“在本机保留一份备用”适合设备内恢复；它不能替代设备损坏时仍可访问的外部副本。

## 恢复到原设备

进入“备份与同步”，选择“从备份文件恢复”或“从文件夹恢复最新备份”，输入密码并仔细检查预览内容后再恢复。配对信息恢复后，应用可能提示重启；如个别主机恢复失败，需重新配对。恢复会改变现有设置，建议先留一份当前备份。

## 换设备与分享 Crown 配置

完整备份面向创建它的设备。更换设备时，先在新设备上重新安装并配对主机，再逐项迁移需要的设置或单独导出 Crown 配置。分享给其他人时，只使用 Crown 配置的专门导出或分享入口，并检查包内信息；不要发送完整备份、备份密码、配对证书或主机地址。

若备份或恢复失败，请记录客户端版本、Android 版本、选择的存储位置、错误提示和预览结果，在 [Issues](https://github.com/qiin2333/moonlight-vplus/issues) 反馈；不要上传原始备份文件。
