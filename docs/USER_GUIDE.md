# Moonlight V+ 功能使用指南

第一次使用，请先看[连接教程](GETTING_STARTED.md)，让手机或平板与电脑在同一网络下成功串流。之后可按目的查阅[特色功能指引](VPLUS_FEATURES.md)、[备份与迁移](BACKUP_AND_MIGRATION.md)或[常见问题](../FAQ.md)。

## 主机端与增强功能

推荐在电脑上安装与 Moonlight V+ 配套的 [Foundation Sunshine](https://github.com/AlkaidLab/foundation-sunshine)。普通 Sunshine 也能提供基础串流；麦克风、电脑屏幕控制等 V+ 功能需要 Foundation Sunshine 提供支持。具体条件见[兼容说明](COMPATIBILITY.md)。

## 麦克风

在串流设置的麦克风分类中开启麦克风，选择每次串流的初始状态；首次使用时按系统提示授予录音权限。可在串流过程中使用麦克风按钮切换状态。没有兼容的主机端、未授予权限或主机端未提供麦克风通道时，麦克风不会开始传输。

## 远程网络与 EasyTier

先确认手机和电脑在同一网络下能成功串流。要从外面连接自己的电脑，可让两端加入同一个 EasyTier 网络，并在应用内查看连接状态。如果显示已连接却找不到电脑，可以手动添加 EasyTier 分配给电脑的地址。核对网络名称和密钥；空 Network Secret 的兼容问题见 [FAQ](../FAQ.md#q-easytier-的-network-secret-留空连不上)。

## 手柄、触控与音频震动

在串流设置中启用需要的虚拟手柄、触控或体感选项。手柄的按键映射、运动传感器和高级触觉取决于连接方式、设备固件、Android 版本及主机端支持。先确认普通按键输入工作，再单独测试体感或触觉；部分功能需要蓝牙、USB 或传感器权限。第一代 Joy-Con 的实现范围见 [Joy-Con 说明](joycon-support.md)。

音频震动可选择设备、手柄或双路输出；如果没有效果，先确认设备本身支持震动，再检查音频震动选项与当前输出设备。音频直通和设备的音频处理路径可能影响效果。

## 备份与配置分享

要恢复这台设备上的设置，请使用“备份与同步”，并妥善保存备份密码。换设备时需要重新配对电脑；分享按键布局时只导出 Crown 配置。操作步骤见[备份与迁移指南](BACKUP_AND_MIGRATION.md)。

## 提交问题

先记录客户端与主机端版本、Android 设备型号、串流分辨率/帧率/编码/HDR/码率和网络路径。附上性能覆盖层数据或经检查的日志；公开 Issue 中请遮盖主机地址、配对信息、证书和其他私人内容。
