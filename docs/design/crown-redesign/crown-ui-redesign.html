Crown / 王冠 · UI Redesign

把王冠，收回应用的设计语言里

王冠现在有三套互不相干的视觉：主应用是浅色玻璃面板 + 粉色强调，串流面板是320dp 的深色工具条，超市又换成了裸 Material 3 与另一套色板。 这版方案不改功能，只做一件事：让王冠的所有界面回到同一套 ui_shell_* token、同一套字号层级、同一套圆角与留白规则，并把「配置 / 编辑 / 绑定 / 分享」重新组织成可读的层级。

01

为什么「不搭」：四个可量化的问题

不是审美偏好问题，而是三套体系并存、token 各自为政、密度与字号失控。完整清单见 docs/CROWN_UI_INVENTORY.md。

A · 体系分裂 三套皮肤，三种语法

主应用是 View + ui_shell_* 浅色玻璃；串流王冠是另一套 320dp 深色工具条；超市是 Compose 且直接 MaterialTheme{} 默认主题，连 DropdownMenu 都是 Material 默认紫。

B · 色彩脱轨 夜间色板方向反了
