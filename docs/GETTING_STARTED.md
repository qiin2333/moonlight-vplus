# 首次连接 Foundation Sunshine

这份指南帮助你把 Android 设备连接到运行 [Foundation Sunshine](https://github.com/AlkaidLab/foundation-sunshine) 的电脑。下文把这台电脑叫作“主机”。先让两台设备在同一网络下成功串流，再尝试其他功能。功能和版本要求见[兼容说明](COMPATIBILITY.md)。

## 1. 准备主机与客户端

1. 从 Foundation Sunshine 的[发布页](https://github.com/AlkaidLab/foundation-sunshine/releases)安装适合主机系统的版本，按主机端引导完成首次配置，并确认它正在运行。
2. 从 Moonlight V+ 的[发布页](https://github.com/qiin2333/moonlight-vplus/releases/latest)安装 Android 客户端。手机、平板或电视盒子与主机先接入同一局域网；有条件时让主机使用有线连接。
3. 首次测试先关闭 VPN 或其他虚拟网络路径，确认普通局域网连接正常后再配置远程访问。

## 2. 添加并配对主机

在 Moonlight V+ 主界面等待电脑出现，然后选择它。客户端显示 PIN（配对码）后，到电脑上的 Foundation Sunshine 网页界面输入配对码。若网页界面提供配对二维码，也可使用客户端的“扫描二维码”入口。

发现不到主机时，先确认两端位于同一网络、主机端正在运行、手机没有切到移动数据或隔离访客网络；然后在客户端手动输入主机的局域网地址。能手动添加但无法串流时，再检查主机防火墙和网络路径。更详细的故障案例见 [FAQ](../FAQ.md)。

## 3. 验证第一条串流

首次测试建议用 1080p 分辨率、60 FPS 帧率、H.264 或自动编码，关闭 HDR，并把码率设为 10–20 Mbps。成功串流后，再逐项提高画质，并单独尝试 HEVC / AV1、HDR 与其他增强功能。一次只改一个设置，方便判断是哪项设置影响了串流。

黑屏或解码失败时，先恢复上述设置并重新连接。画面卡顿时，先降低码率；还可打开性能信息，查看是否有丢包或延迟突然升高。Android TV / 盒子先用 H.264 测试，再尝试其他编码。

## 启用麦克风

在串流设置的麦克风分类中开启功能，选择初始状态；第一次使用时授予 Android 录音权限。连接后可用串流内麦克风按钮切换。主机端必须支持麦克风重定向并在连接时提供麦克风通道；最低版本的文档依据及核验状态见[兼容矩阵](COMPATIBILITY.md)。如果按钮可见但没有声音，先检查权限、初始状态、主机端麦克风配置及主机应用选用的输入设备。

## 远程连接

确认局域网连接稳定后，再使用 EasyTier、Tailscale 或其他远程网络。虚拟网络中发现不到主机时，尝试使用主机的虚拟 IP 手动添加。EasyTier 的网络名称、密钥、节点及虚拟地址须在两端对应；不要把配对证书、网络密钥或主机公网地址直接贴到公开 Issue。
