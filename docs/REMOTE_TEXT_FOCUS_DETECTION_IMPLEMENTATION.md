# 手动键盘与远端输入避让

## 当前行为

- 客户端不根据 UIA/InputPane 自动弹出键盘，不抢焦点或重启输入连接；用户使用现有手动入口。
- 主机上下文仅作为几何提示，不增加协议字段、应用名单或光标识别。
- 优先使用捕获范围内、位于元素矩形内的 caret；否则使用合法的匹配点击锚点。不能用整个 Document 底边代替输入位置。
- 停靠键盘按 Android IME Insets 避让；明确隐藏时撤销自动偏移。仅在没有 Insets 时使用 visible-frame 回退。浮动键盘 bottom=0 时不猜测遮挡区域。

## 生命周期与用户控制权

- 键盘打开时仅消费一次最近 5 秒内收到的上下文，并锁定本轮目标；关闭后不复用旧目标。
- 5 秒是客户端接收新鲜度，不证明主机快照年龄。
- 用户平移或缩放后冻结临时偏移，不再自动抵消用户操作；关闭、重置会话或销毁时撤销临时偏移，保留基础平移/缩放。
- 目标失活时停止自动避让；若用户已经接管，则保留当前临时偏移直到键盘关闭。画面和指针覆盖层同步移动。

## 能力边界

UIA 的 TextEditPattern 可存在于只读 Chrome Document，不能证明编辑意图；InputPane 也不是全布局、全应用的键盘可见性证明。缺少可信几何时手动键盘仍可使用，但不承诺自动定位。客户端不读取主机文本，也不替应用滚动文档。

键盘打开期间不自动跟随其他输入框。浮动键盘、双指缩放、动画全过程、分屏/旋转和不同厂商 IME 仍需专项验收。

## 回归验证

- 策略单元测试覆盖上下文校验、坐标边界、遮挡计算、过期与一次性消费、用户接管和重置。
- 模拟器集成测试保留两条：实际软键盘打开后目标可见并在隐藏后恢复；生产手势平移不被后续 Insets 抵消，重开不复用旧锚点。
- 模拟器上下文为合成输入，不代表真实 Sunshine 串流或所有第三方键盘已完成验收。
