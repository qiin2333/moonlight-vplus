# Moonlight V+ 有哪些特色功能

如果还没连接过电脑，先按 [Foundation Sunshine 首次连接教程](GETTING_STARTED.md)完成配对和第一次串流。下文的“主机”是运行 Foundation Sunshine 的电脑；“串流菜单”是进入游戏或桌面后打开的操作菜单。

| 我想…… | 从这里开始 |
| --- | --- |
| 在触屏上摆放游戏按键 | 设置 → 王冠 → 管理 Crown 配置 |
| 使用别人分享的按键布局 | 设置 → 王冠 → 超市王冠 |
| 玩游戏时调整画质或执行电脑上的操作 | 串流菜单 → 调整码率 / 超级指令 |
| 把画面送到外接屏 | 设置 → 把串流发送到外接显示器 |
| 用手机麦克风语音 | 串流设置 → 麦克风 |
| 让声音带来振动反馈 | 设置 → 音频 → 音频模拟振动输出 |
| 在外面连接自己的电脑 | 应用内 EasyTier 面板 |
| 尝试插帧 | 设置 → 帧生成 → 检查设备支持 |

## 王冠：保存和切换触屏按键

一套 Crown 配置可以保存屏幕按键、快捷动作、触控方式和振动设置。先在“管理 Crown 配置”中建立一套布局，进入游戏测试后再调整。串流时可从“王冠”入口切换布局、编辑或暂时隐藏按键。

“超市王冠”提供其他用户分享的布局。导入前看适配的游戏和设备；要分享自己的布局，请使用 Crown 的导出或分享入口。向社区投稿需要连接 GitHub 并提交给维护者审核。不要把包含电脑配对信息的[完整备份](BACKUP_AND_MIGRATION.md)发给别人。

## 串流时控制 Foundation Sunshine

网络变差时，打开串流菜单的“调整码率”，降低码率后观察画面是否更稳定。“超级指令”用于执行事先在 Foundation Sunshine 中配置的电脑操作；列表为空时，先检查电脑上的配置。

显示器控制和麦克风也需要电脑端支持。看到菜单入口却无法使用时，检查 Foundation Sunshine 的设置和双方版本；[兼容说明](COMPATIBILITY.md)列出了已知条件。

## 外接屏、麦克风和振动

- **外接屏：**先接好屏幕，打开“把串流发送到外接显示器”，确认普通画面和声音正常，再尝试 HDR 或更高刷新率。电脑有多块屏幕时，可另外选择要串流的电脑屏幕。
- **麦克风：**首次使用要授予 Android 录音权限，电脑端也要启用麦克风通道。具体步骤见[首次连接教程](GETTING_STARTED.md#启用麦克风)。
- **音频模拟振动：**把声音变化转换为手机或手柄的振动。它与游戏自身提供的手柄振动是两种功能；可在“场景模式”中选择效果。

## 在外面连接自己的电脑

先确保在同一网络下能正常串流，再配置 EasyTier。连接虚拟网络后，如果列表里没有电脑，可手动添加 EasyTier 分配给电脑的地址。更多排查步骤见[远程连接](GETTING_STARTED.md#远程连接)。

## 插帧：进阶功能

“帧生成”需要先开启开发者功能。进入“检查设备支持”查看设备是否满足 Android 10、64 位 ARM 处理器和 Vulkan 1.1 等要求。首次使用还要从自己安装的 Lossless Scaling 中导入 `Lossless.dll`。

若目标是 120 Hz 输出，应用提示先把串流帧率设为 60 FPS。网络丢帧时可另试“弱网补帧”。画面异常时先关闭插帧，确认普通串流恢复正常。
